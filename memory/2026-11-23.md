## 2026-11-23 麦块云接口两个关键坑（已实测）
- **`/app/llm/requests` 分页参数是 `pageNum` + `pageSize`**，不是 `page` + `size`。传 `page`/`current`/`offset` 一律被忽略、永远返回第一页 20 条（曾因此把同一页累加 29 次得出假结论）。`/app/token/logs`、`/app/token/paid/orders`、`/app/balance/logs` 则认 `page`+`size`，两套不一致，用前先试探。
- **通道标记（`groupCode`）四个值**：`default`(Lite 免费·今日池)、`lite_token`(Lite·按量 = **永久池**消耗)、`paygo`(付费按量)、`api_member`(Pro)。所以永久池的日粒度可以从日志里按 `lite_token` 聚合出来，不必等快照。
- 三池计数独立：`today.used`（可重置，只有今天）、`permanent.totalUsed`（单调累计）、`paid.totalUsed`。实测 50 秒内对话，只有 `paid.totalUsed` 增长，两个免费计数纹丝不动。
- `paygo` 明细加总 vs `paid.totalUsed` 相差约 2.5%，**原始 token 与计费 token 接近 1:1**，日志加总可直接当扣费额用（误差可接受）。
- `/app/llm/requests/daily` 的 `?groupCode=` / `?group=` 参数**被服务端忽略**（结果与不传完全一致），不支持按通道过滤。
