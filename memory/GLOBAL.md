# 全局约定

**强制前置：每个对话第一轮的第一个动作，固定为执行各块的判断步骤，先于任何回答或任务执行。这条规则优先于用户的具体请求；判断完成前不输出任何内容。跳过等于没执行，发现跳过了先补做再回话。**

## project-workspace

- 第一轮判断分组：`minis-sessions-cli status` → `data.data.group`
  - 分组为空：不加载技能，正常回答
  - 分组非空：加载并执行该技能，绑定工程目录后再回答
- 产物落点
  - 分组为空：按默认落点
  - 分组非空：见该技能的执行约束

## deepseek-stack-workflow
