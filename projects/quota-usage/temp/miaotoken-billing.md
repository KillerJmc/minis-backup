# 妙词元：额度与 token

站点 `api.miaotoken.cn`（New API v1.0.0-rc.22）。适用 ChatGPT 系模型。

**目的**：查已用的 token 构成，以及剩余的钱相当于多少 token。

---

## 一、换算

| 换算 | 公式 |
|---|---|
| 人民币 → 美元 | 1 元 = 1 美元 |
| 额度 ↔ 美元 | 额度 = 美元 × 500 000 |
| 美元 → token | token = 美元 × 1 000 000 ÷ 单价 |

单价单位：美元/百万 token。

```
单价 = 表达式系数 × 分组倍率
```

额度基数 `500 000` 来自站点字段 `quota_per_unit`。

---

## 二、已用 token：直接统计

已消耗的 token 是既定事实，不做任何换算，只从日志分类累加。

一次请求的输入只有两部分，互不重叠，合计等于 `prompt_tokens`。

| 类别 | 统计方式 |
|---|---|
| 未命中输入 | `prompt_tokens − cache_tokens` |
| 缓存读 | `cache_tokens` |
| 输出 | `completion_tokens` |

```
GET /api/log/self?type=2   逐页取完，p 从 1 开始
未命中 += prompt_tokens − cache_tokens
缓存读 += cache_tokens
输出   += completion_tokens
```

`p=0` 与 `p=1` 返回同一页，从 1 开始并按 `id` 去重。

**无缓存写。** OpenAI 的 usage 只上报缓存读 `cached_tokens`；缓存写 `cache_creation_tokens` 是 Anthropic 的字段。站点表达式里的 `cc` 项属通用写法，GPT 流量下恒为 0。

---

## 三、剩余 token：需要单价

```
剩余额度 = GET /api/user/self 的 quota 字段
剩余美元 = 剩余额度 ÷ 500 000
剩余 token = 剩余美元 × 1 000 000 ÷ 单价
```

同一笔剩余额度，按不同单价换算，结果相差可达数十倍。必须指定模型、类别与配比。

```
额度 = 每次价格 × 分组倍率 × 图片数
```

### 倍率制（1 个）

`codex-auto-review`：模型倍率 2.5、输出倍率 6、缓存倍率 1、可用分组 codex不降智。

```
单价（输入）= 模型倍率 × 分组倍率 × 0.5
单价（输出）= 输入单价 × 输出倍率
单价（缓存读）= 输入单价 × 缓存倍率
```

## 五、注意事项

**核对历史别用当前定价。** 站点改过分组归属，用现价复算历史会得出错误金额。该条日志的 `other` 字段存有当时的快照：

| 字段 | 含义 |
|---|---|
| `expr_b64` | 当时的计费表达式 |
| `group_ratio` | 当时的分组倍率 |
| `cache_tokens` | 当时的缓存读 token |
| `matched_tier` | 当时命中的档位 |

**长文档档位未验证。** 本账户 1789 条记录中 `prompt_tokens` 最大 250 906，未达 272 000 门槛，长文系数只有配置依据。

### 扣费公式校验

已用 token 分类统计之外，另用单条日志验证单价口径。

```
模型 gpt-6.1-sol   分组 codex特价（倍率 0.1）
prompt_tokens 50 813   cache_tokens 41 915   completion_tokens 78

未命中 = 50 813 − 41 915 = 8 898
成本   = 8 898×2 + 78×10 + 41 915×0.2 = 26 959
额度   = 26 959 × 0.5 × 0.1 = 1 347.95 → 1 348
```

日志实记 1 348，一致。

全量 1 789 条逐条复算，零超差，合计差 45 额度（取整）。
