### 2026-11-23 · v1.2.4 采用 Angular 提交规范
- 明确规定 commit 采用 **Angular 提交规范**，标题格式 `<类型>(<范围>): <主题>`。
- 补三段含义：类型（小写类型词）、范围（名词、影响范围）、主题（命令式现在时、不加句号、≤50 字符）。
- 类型子集收敛为 feat / fix / docs / test / chore 五个，允许 Angular 原生的 refactor / perf，禁止自创 update、change、调整。
- 正文强调“为什么”而非“做了什么”；脚注按 Angular 写 `BREAKING CHANGE:`，不自造格式。
- 标题行 50 字上限、中英文混排保持类型词与范围词小写。
