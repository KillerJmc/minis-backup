# 测试说明

## 怎么跑

```sh
python3 tests/run.py              # 全部用例，末行「共 15 项，失败 0 项」
python3 tests/run.py --verbose    # 失败时打印完整输出
python3 tests/run.py --selftest   # 负向自检：把每条用例的期望判反，应当全部变红
```

**每个用例都跑在真实目录的副本上**：先把 `/var/minis/mounts/Minis` 整棵复制到 `tempfile.mkdtemp()` 作主副本，各用例再从主副本**真实复制**一份独立沙箱（整份约 3 MB / 1100 个文件）。真实目录只读，跑完清理；启动时先清掉上次中断留下的沙箱（主副本 `mgb-master-*` 保留）。

早先用过硬链接派生沙箱，速度快但**所有沙箱共享 inode**：用例里任何原地写（脱敏改写、git 往 `logs/HEAD` 追加、用例自己 append 文件）都会穿透到主副本，把干净基线弄脏，后续用例随即出现「没有可提交的改动」「内层仓库没进备份」这类与代码无关的假失败。改成真实复制后这类污染彻底消失。

## 并发

```sh
python3 tests/run.py --jobs 2     # 或 --jobs=2 / MGB_JOBS=2
```

**默认串行**。iSH 是 aarch64 模拟层，这些用例又都是 I/O 密集（每例复制 1100+ 文件，再让 git deflate 上千个对象），多线程只会让 syscall 互相争抢。15 项全量实测：

| 线程数 | 耗时 |
|---|---|
| 1 | **374s** |
| 2 | 590s |
| 5 | 736s |

越开越慢，所以开关留着但默认关。想要快，只能减少用例里的备份工作量，加线程没有用。

## 绝不碰真实远程

所有用例的远程都是 `/tmp` 下的裸仓库，并且全程设置 `BACKUP_GIT_NO_NETWORK=1`，脚本遇到 `https://` 地址会直接拒绝。这样即使误配了 token 也不会推到你的 GitHub。

`T10` 专门验证这条保护：设了禁网却要推 https 地址时必须失败，并且 `.git` 要恢复原状。

## 副本长什么样

```
<临时目录>/Minis/           ← 真实挂载目录的复制（跳过根 .git、bak/、restore/）
├── memory/                 ← 真实记忆，含已脱敏的历史
├── projects/*/             ← 真实工程，各自带 .git（含内层嵌套）
├── skills/                 ← 部署产物
└── skills-dist/            ← 打包好的 zip
```

测试里临时写入的敏感数据一律用假值（`Secret12345`、`13800001111`），不碰真实凭据。

## 用例字段

| 字段 | 说明 |
|---|---|
| `name` | 对话级描述：用户说什么 → 期望什么 |
| `kind` | 场景类型，对应 `run.py` 里的 `RUNNERS` |
| `expect` | 输出里必须出现的字符串 |
| `rc` | 期望退出码，默认 0 |
| `args` | 传给 `backup.py` 的参数 |
| `assert_file` | 断言沙箱里存在这些路径 |
| `assert_no_remote` | 断言没有配置 origin |

## 覆盖了什么

| 用例 | 验证 |
|---|---|
| T1–T2 | 初始化只做本地，不配远程 |
| T3–T4 | 参数校验，未知子命令不当位置参数 |
| T5 | 预演列出全部仓库且**不改名** |
| T6 | 提交后 `.git` 全部恢复、无残留、工作区没有内容改动 |
| T7 | 子目录 `.gitignore` 也改名，内层嵌套仓库不被静默排除 |
| T8 | 第二轮备份照常工作 |
| T9 | 推送后回验：远程能克隆回来完整还原 |
| T10 | 禁网时拒绝推 https，且失败后 `.git` 恢复 |
| T11 | 空目录还原：整份铺入，不建 `bak/` |
| T12 | 非空且无 `.git`：停下，rc=6 |
| T13 | 有 `.git` 还原：旧内容进 `bak/`，`bak` 目录名可读 |
| T14 | 扫描敏感信息：报告不打明文，`--fix` 后密码全星号 |
| T15 | 提交信息符合 Angular |

`T7` 是对应用最关键的一条：`projects/a/.gitignore` 里的 `/*/` 会作用于备份仓库，不改名的话内层仓库整个进不了备份。

`--selftest` 把每条用例的期望判反，必须全部变红，否则说明断言太松。
